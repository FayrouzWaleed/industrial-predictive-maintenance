# Industrial Predictive Maintenance

A machine learning project that predicts potential machine failures from operational sensor readings, with an interactive Streamlit dashboard for exploring data and testing predictions.

## Project Goals

* Explore industrial sensor data and understand machine failure patterns.
* Build and evaluate machine learning models for failure prediction.
* Investigate class imbalance and the trade-off between false alarms and missed failures.
* Select a decision threshold using validation data.
* Develop an interactive dashboard with Streamlit.

## Dataset

This project uses the AI4I 2020 Predictive Maintenance Dataset from the UCI Machine Learning Repository.

Dataset source: https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset

The dataset contains machine operating conditions, sensor measurements, and failure labels.
